# Solicitação de entrada de material — UFC-INFRA

**Acesse o aplicativo:** https://rios-impassiveis.github.io/solicitacao-ufc-material/

Aplicativo para moradores das **Comunidades dos Galpões e da Hidráulica** pedirem à UFC-INFRA autorização para entrar com material de construção pela portaria do Campus do Pici.

O morador preenche o formulário no celular e o aplicativo gera um **PDF em A4**, pronto para enviar pelo WhatsApp ou imprimir e entregar na UFC-INFRA.

## Como usar

1. Abra o link acima no celular, de preferência no **Chrome**.
2. Preencha os 7 passos:
   1. nome;
   2. telefone;
   3. comunidade;
   4. referência da casa (opcional);
   5. por que precisa da reforma, com fotos;
   6. material que vai entrar pela portaria;
   7. período previsto para a obra.
3. Toque em **Gerar PDF para a UFC**.
4. O PDF fica salvo na pasta **Downloads** do aparelho. Mande pelo WhatsApp para a UFC-INFRA ou imprima e leve até lá.

Se o link for aberto dentro do WhatsApp e o PDF não baixar, toque nos três pontinhos e escolha **Abrir no Chrome**.

## Privacidade

Nada do que é preenchido é enviado para a internet. O PDF é montado no próprio celular. Nome, telefone, comunidade e referência da casa ficam guardados só naquele aparelho, para facilitar o próximo pedido.

## Autenticidade

Aplicativo desenvolvido pela **Organização Popular Terra Liberta** para uso de moradores das comunidades. A UFC deve conferir a autenticidade entrando em contato com o morador requerente.

## Para quem mantém o repositório

- O aplicativo é um único arquivo: `index.html`. A logo vem embutida no arquivo, e o PDF é gerado pela biblioteca jsPDF.
- Para atualizar, suba um novo `index.html` por cima do antigo em **Add file → Upload files** e clique em **Commit changes**. O site se atualiza em 1 ou 2 minutos.
- A publicação está configurada em **Settings → Pages**: branch `main`, pasta `/ (root)`.
